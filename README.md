# Ajay Kumar — Developer Portfolio

A responsive developer portfolio built with HTML5, custom CSS, Bootstrap 5, Bootstrap Icons, and vanilla JavaScript.

## Sections

1. Navigation
2. Hero / introduction
3. About
4. Skills
5. Services
6. Selected projects
7. Experience and learning journey
8. Working approach
9. Contact
10. Footer

## Folder structure

```
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Run locally

1. Clone or download this repository.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. An internet connection is needed for the Bootstrap, Bootstrap Icons, and Google Fonts CDNs.

## Personalize before publishing

- Replace `hello@example.com` with your real email address in `index.html` and `js/script.js`.
- Update the LinkedIn URL with your profile.
- Replace the example project cards with real project descriptions and links.
- Add your actual experience, education, and verified achievements.
- Add a profile photo if you want one; the current hero uses a CSS code-card illustration.
- The contact form opens the visitor's email application. For direct submissions, connect a backend or a form service.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the default branch and the `/(root)` folder, then save.
4. Wait for the deployment and open the published URL shown in the Pages settings.
